# ACB-PZBL-Inventory-Tracker

An inventory tracking software project 
# Goal
- Store all inventory listing and quantity
- Track inventory on a weekly basis
- Notify you when inventory run low

## Project Description
This inventory track is a Python base program designed to record and track inventory of any web-store and notify you when inventory run low. 

## Goals
The project aims to help reduce the tedious task of manually tracking and inputing inventory in an excel or docs file.

## Planned Features
- Be able to track and notify the users of inventory status weekly
- Be able to read data from an excel file and edit the file

## Tools
Python - Primary coding language 
Github - Coding repository and free public code libraries 
Visual Studio Code - Primary coding software
Excel - A basic inventory and spreadsheet software
